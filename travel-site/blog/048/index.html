ANA国内線特典航空券の必要マイル

ANA国内線特典航空券は何マイル必要か。2026年5月19日以降の新しい必要マイル、シーズン、距離区分をANA公式情報をもとに整理します。

2026年10月確認
制度・必要マイル・キャンペーンは変更される場合があります。予約・交換前にANA公式サイトで最新条件を確認してください。

2026年5月19日以降は新しい条件で確認する

ANA国内線特典航空券は、搭乗日・区間・シーズンによって必要マイルが変わります。2026年5月19日以降の直行1区間は、0〜300マイル区間が6,000 / 6,500 / 9,000マイル、301〜800マイル区間が7,000 / 8,500 / 10,500マイル、801〜1,000マイル区間が8,000 / 9,500 / 12,000マイル、1,001〜2,000マイル区間が9,500 / 10,500 / 13,000マイル（L / R / H）です。

必要マイルは「日付→距離→チャート」の順で見る

まず搭乗日のシーズンを確認し、次に区間の基本マイレージを確認、そのうえで必要マイルチャートを見るのが基本です。往復は往路と復路をそれぞれ計算して合算します。

増田裕一が初心者におすすめする確認方法

数字を暗記するより、旅行日と行き先が決まった時点でANA公式のマイル計算シミュレーターを使う方が確実です。制度は変更されるため、本サイトでも固定情報として思い込まず、公式情報を確認する前提で解説します。
